# Simulador de média

Página estática em HTML, CSS e JavaScript, com layout responsivo para celular. Não usa servidor ou dependências. Notas e matérias personalizadas ficam salvas automaticamente no navegador do próprio aluno.

Inclui as matérias deste semestre, a média parcial, o cálculo da P2 e um criador de matérias com avaliações e pesos configuráveis. Os dados não sincronizam entre aparelhos; em computadores compartilhados, use **Apagar todos os dados salvos** ao terminar.
